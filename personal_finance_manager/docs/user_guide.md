# User Guide

## Running the Application

Open a terminal in the project folder and run:

```bash
python main.py
```

## Menu Options

1. Add New Expense - Enter amount, category, date and description.
2. View All Expenses - Display all saved expenses.
3. View Category-wise Summary - Show total and average expenses and category totals.
4. Generate Monthly Report - Generate a text report for a selected month.
5. Search Expenses - Search by date, category or description.
6. Backup Data - Copy the CSV data to the backups folder.
7. Restore Data - Restore data from the backup.
8. Exit - Save data and close the application.

## Date Format

Use `YYYY-MM-DD`, for example:

`2026-10-08`

For monthly reports use:

`YYYY-MM`
